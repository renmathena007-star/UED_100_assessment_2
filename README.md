# Coles Online Prototype (UED100 Assessment 2)

A simple, responsive grocery-shop prototype made with plain HTML, CSS and JavaScript in Visual Studio Code. No frameworks.

## How to run
Unzip, open the folder, double-click `index.html`.

## Files
- `index.html`: all the content (header, navbar, 8 products, cart, contact form, footer)
- `styles.css`: the look and the responsive rules
- `script.js`: cart, search, menu button, form checks
- `images/`: SVG pictures
- `REFERENCES.md`: APA 7 references for the citations in the comments
- `TESTING.md`: test table and validation tools

## How it was built
The page layout (header, navigation bar, two columns, footer, media queries) follows the structure taught in the W3Schools
tutorial "How TO - Make a Website" (W3Schools, n.d.-k), adapted into a grocery shop. The code was produced with AI help
(see the AI acknowledgement below).
